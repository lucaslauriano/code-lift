`N` cards lie in a row. Card `i` shows the number `A[i]`.

The **MEX** of the row is the smallest positive integer that no card currently shows. (It starts at
`1`, not `0`.)

Repeat this move: compute the MEX. If it is greater than `N`, stop. Otherwise flip the card at
position `MEX - 1` so that it shows `MEX`, and count one operation.

Return the number of operations performed.

## Examples

| A              | answer | why                                                     |
| -------------- | ------ | ------------------------------------------------------- |
| `[3, 2, 1]`    | `0`    | MEX is `4 > 3`, nothing to do                           |
| `[2, 1, 4]`    | `1`    | MEX is `3`; flip position 2 to `3`, then MEX is `4 > 3` |
| `[1, 3, 5, 7]` | `3`    | flip to `2`, then to `3`, then to `4`                   |

Watch the second example of the third row: flipping position 1 to `2` destroys the only `3` on the
table, so `3` becomes missing again. The MEX does **not** only move forward.

## Assumptions

- `N` is an integer within the range `[1 .. 100,000]`.
- Each element of `A` is an integer within the range `[-1,000,000,000 .. 1,000,000,000]`.
- The process always terminates.
- Expected worst-case time complexity is `O(N log N)`.
