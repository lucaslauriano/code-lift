An array `A` of `N` distinct integers is given. The array holds values from the range
`[1 .. (N + 1)]`, which means exactly one value from that range is missing.

Return the missing value.

## Examples

| A              | answer |
| -------------- | ------ |
| `[2, 3, 1, 5]` | `4`    |
| `[1, 2, 3]`    | `4`    |
| `[2, 3, 4]`    | `1`    |
| `[]`           | `1`    |

An empty array holds no values from the range `[1 .. 1]`, so `1` is missing.

## Assumptions

- `N` is an integer within the range `[0 .. 100,000]`.
- The elements of `A` are all distinct.
- Each element of `A` is an integer within the range `[1 .. (N + 1)]`.
- Expected worst-case time complexity is `O(N)`, with `O(1)` extra space.
