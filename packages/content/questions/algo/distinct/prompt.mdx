Write a function that, given an array `A` consisting of `N` integers, returns the number of distinct
values in that array.

For example, given the array `[2, 1, 1, 2, 3, 1]` the function should return `3`, because there are
three distinct values: `1`, `2` and `3`.

## Examples

| A                    | answer |
| -------------------- | ------ |
| `[2, 1, 1, 2, 3, 1]` | `3`    |
| `[]`                 | `0`    |
| `[5, 5, 5]`          | `1`    |

## Assumptions

- `N` is an integer within the range `[0 .. 100,000]`.
- Each element of `A` is an integer within the range `[-1,000,000 .. 1,000,000]`.
- Expected worst-case time complexity is `O(N log N)`.
