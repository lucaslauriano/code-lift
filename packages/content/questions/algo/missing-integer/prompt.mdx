Write a function that, given an array `A` of `N` integers, returns the smallest positive integer
(greater than 0) that does **not** occur in `A`.

For example, given `A = [1, 3, 6, 4, 1, 2]`, the function should return `5`. Given
`A = [1, 2, 3]`, the function should return `4`. Given `A = [-1, -3]`, the function should return `1`.

## Examples

| A | answer |
| --- | --- |
| `[1, 3, 6, 4, 1, 2]` | `5` |
| `[1, 2, 3]` | `4` |
| `[-1, -3]` | `1` |

## Assumptions

- `N` is an integer within the range `[1 .. 100,000]`.
- Each element of `A` is an integer within the range `[-1,000,000 .. 1,000,000]`.
- Expected worst-case time complexity is `O(N)`.
