You are given an array of integers `nums` and an integer `target`. Exactly one pair of distinct
positions in `nums` adds up to `target`.

Return those two positions as an array `[i, j]` with `i < j`.

## Examples

| nums             | target | answer   |
| ---------------- | ------ | -------- |
| `[2, 7, 11, 15]` | `9`    | `[0, 1]` |
| `[3, 2, 4]`      | `6`    | `[1, 2]` |
| `[3, 3]`         | `6`    | `[0, 1]` |

## Assumptions

- The length of `nums` is within the range `[2 .. 100,000]`.
- Each element is an integer within the range `[-1,000,000,000 .. 1,000,000,000]`.
- Exactly one valid pair exists, and you may not use the same position twice.
- Expected worst-case time complexity is `O(N)`.
