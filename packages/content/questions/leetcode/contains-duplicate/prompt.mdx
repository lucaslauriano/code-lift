Given an integer array `nums`, return `true` if any value appears at least twice, and `false` if
every element is distinct.

## Examples

| nums                             | answer  |
| -------------------------------- | ------- |
| `[1, 2, 3, 1]`                   | `true`  |
| `[1, 2, 3, 4]`                   | `false` |
| `[1, 1, 1, 3, 3, 4, 3, 2, 4, 2]` | `true`  |

## Assumptions

- The length of `nums` is within the range `[1 .. 100,000]`.
- Each element is an integer within the range `[-1,000,000,000 .. 1,000,000,000]`.
