Two sorted linked lists are given. Splice them into one sorted list and return its head.

The result should reuse the nodes of the two inputs rather than allocate new ones.

A node is a plain object:

```ts
interface ListNode {
  val: number;
  next: ListNode | null;
}
```

## Examples

| list1       | list2       | answer                  |
| ----------- | ----------- | ----------------------- |
| `1 → 2 → 4` | `1 → 3 → 4` | `1 → 1 → 2 → 3 → 4 → 4` |
| empty       | empty       | empty                   |
| empty       | `0`         | `0`                     |

## Assumptions

- Each list holds between `0` and `50,000` nodes.
- Each `val` is an integer within the range `[-100 .. 100]`.
- Both lists are already sorted in non-decreasing order.
