Given two strings `s` and `t`, return `true` if `t` is an anagram of `s` — that is, if it uses
exactly the same letters the same number of times, in any order.

## Examples

| s           | t           | answer  |
| ----------- | ----------- | ------- |
| `"anagram"` | `"nagaram"` | `true`  |
| `"rat"`     | `"car"`     | `false` |
| `"a"`       | `"ab"`      | `false` |

## Assumptions

- Both strings have length within the range `[0 .. 100,000]`.
- Both consist of lowercase English letters only.
