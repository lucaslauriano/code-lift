Given a sorted array of distinct integers `nums` and an integer `target`, return the index of
`target`, or `-1` if it is not there.

You must write an algorithm with `O(log N)` runtime.

## Examples

| nums                   | target | answer |
| ---------------------- | ------ | ------ |
| `[-1, 0, 3, 5, 9, 12]` | `9`    | `4`    |
| `[-1, 0, 3, 5, 9, 12]` | `2`    | `-1`   |
| `[5]`                  | `5`    | `0`    |

## Assumptions

- The length of `nums` is within the range `[1 .. 100,000]`.
- All values are distinct and sorted in ascending order.
- Each value and `target` is within the range `[-10,000 .. 10,000]`.
