There are `numCourses` courses, numbered `0` to `numCourses - 1`. The array `prerequisites` lists
pairs `[a, b]`, meaning you must take course `b` before course `a`.

Return `true` if it is possible to finish every course, and `false` otherwise.

## Examples

| numCourses | prerequisites      | answer  |
| ---------- | ------------------ | ------- |
| `2`        | `[[1, 0]]`         | `true`  |
| `2`        | `[[1, 0], [0, 1]]` | `false` |
| `1`        | `[]`               | `true`  |

The second row is impossible: each course requires the other.

## Assumptions

- `numCourses` is within the range `[1 .. 100,000]`.
- `prerequisites` holds at most `100,000` pairs.
- Pairs may repeat, and both values are valid course numbers.
