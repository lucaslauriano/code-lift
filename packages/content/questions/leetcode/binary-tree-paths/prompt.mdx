Given the root of a binary tree, return every root-to-leaf path as a string, with the values joined
by `"->"`.

Paths may come back in any order.

A tree node is a plain object:

```ts
interface TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
}
```

## Examples

| tree                     | answer                |
| ------------------------ | --------------------- |
| `1 → (2 → (null, 5), 3)` | `["1->2->5", "1->3"]` |
| `1`                      | `["1"]`               |
| `null`                   | `[]`                  |

## Assumptions

- The tree holds between `0` and `100` nodes.
- Each `val` is an integer within the range `[-100 .. 100]`.
- Order does not matter; this question's cases list paths left to right.
